# 05 — Reliability & Failure Scenarios Audit (Phase 5)

- **Scope**: Đánh giá khả năng chịu lỗi, tính nhất quán dữ liệu sau lỗi, xử lý timeout/status code, Redis/PostgreSQL outage, Outbox/Worker crash, SSE disconnect, concurrent updates, và duplicate submissions (kết hợp phân tích mã nguồn sâu + kiểm chứng runtime không phá hủy).
