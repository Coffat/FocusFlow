# FocusFlow Frontend

Ứng dụng Frontend Next.js 15 App Router cho FocusFlow, xây dựng với React 19, TypeScript, Tailwind v4, TanStack Query và Zustand.

## Khởi chạy với `pnpm`
```bash
# Cài đặt dependencies
pnpm install

# Chạy server phát triển (Development server)
pnpm dev

# Build production
pnpm build
```
