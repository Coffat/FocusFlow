# FocusFlow

## Overview
FocusFlow is a productivity and workflow management project.

## Project Structure

```text
FocusFlow/
│
├── .agents/          # Agent configuration, rules, and skills
│   ├── rules/        # Guidelines and coding standards for AI agents
│   └── skills/       # Specialized agent capabilities and scripts
│
├── docs/             # Documentation
│   ├── requirements/ # Business & functional requirements
│   ├── srs/          # Software Requirements Specifications (SRS)
│   ├── uml/          # UML diagrams & designs
│   ├── architecture/ # Architecture design documents
│   ├── database/     # Database schemas, ERDs, and migrations
│   └── decisions/    # Architecture Decision Records (ADRs)
│
├── src/              # Application source code
├── tests/            # Test suites
├── README.md         # Project overview and documentation
└── AGENTS.md         # Agent guidelines and workflows
```
